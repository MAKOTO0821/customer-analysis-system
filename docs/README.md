# 顧客ファイル管理システム

プロジェクトの概要をここに記述します。

## 📋 プロジェクト概要

このシステムは、顧客情報、販売記録、および関連ドキュメントを一元管理するためのシステムです。

## 🎯 主な機能

- 顧客情報管理
- 販売記録の追跡
- ドキュメント整理
- レポート生成

## 📁 ファイル構成

```
顧客ファイル/
├── README.md                  # このファイル
├── customers.json             # 顧客マスタデータ
├── sales-records.csv          # 販売記録
├── my-todo-list.txt           # タスク管理
└── internal-sns/              # 内部プロジェクト
```

## 🚀 使用方法

### 1. 顧客情報の確認
`customers.json` ファイルで顧客マスタを確認できます。

```json
{
  "id": 1,
  "name": "田中太郎",
  "company": "ABC株式会社",
  "status": "active"
}
```

### 2. 販売記録の確認
`sales-records.csv` ファイルで販売データを確認できます。

## 💡 よくある質問（FAQ）

**Q: ファイルはどこに保存されていますか？**
- A: `C:\Users\user\OneDrive\デスクトップ\顧客ファイル` に保存されています。

**Q: 新しい顧客を追加するには？**
- A: `customers.json` を編集して、新しい顧客オブジェクトを `customers` 配列に追加してください。

**Q: 販売記録をエクセルで見たい場合は？**
- A: `sales-records.csv` をエクセルで開いてください。
